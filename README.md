
# Predicción de la generación de residuos sólidos en Colombia mediante Deep Learning

## Descripción del proyecto

Este proyecto busca aplicar técnicas de Deep Learning para analizar y predecir la generación de residuos sólidos en Colombia, utilizando información estadística de fuentes oficiales.

Se propone implementar redes neuronales recurrentes LSTM (Long Short-Term Memory), con el propósito de identificar patrones y tendencias que permitan apoyar la toma de decisiones en la gestión de residuos sólidos.

## Objetivo general

Desarrollar un modelo de Deep Learning basado en redes neuronales LSTM para predecir la generación de residuos sólidos en Colombia a partir de datos estadísticos.

## Técnica utilizada

- Deep Learning.
- Redes neuronales recurrentes (LSTM).
- Python.
- Pandas y NumPy.
- TensorFlow y Keras.

## Fuentes de datos

Se contempla utilizar información de fuentes oficiales como:

- Departamento Administrativo Nacional de Estadística (DANE).
- Sistema Único de Información de Servicios Públicos (SUI).

Los conjuntos de datos específicos se documentarán una vez seleccionados y verificados.

## Estructura del proyecto

- datos/: conjuntos de datos utilizados.
- notebooks/: desarrollo del modelo en Python.
- resultados/: gráficas y resultados de las predicciones.
- imagenes/: evidencias del proyecto.
- referencias/: fuentes bibliográficas.
