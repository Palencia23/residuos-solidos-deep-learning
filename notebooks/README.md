
# Notebooks del proyecto

En esta carpeta se almacenarán los cuadernos de Jupyter Notebook utilizados para desarrollar la investigación.

Se realizarán los siguientes procesos:

- Importación de librerías.
- Carga de datos estadísticos.
- Limpieza y transformación de datos.
- Análisis exploratorio.
- Construcción de la red neuronal LSTM.
- Entrenamiento y evaluación del modelo.
- Predicción de la generación de residuos sólidos en Colombia.
