
# Datos del proyecto

Esta carpeta contiene los conjuntos de datos utilizados en la investigación sobre la predicción de la generación de residuos sólidos en Colombia.

Se utilizarán datos estadísticos de fuentes oficiales, como el DANE y el Sistema Único de Información (SUI).

Los datos serán revisados, organizados y preparados para su utilización en el modelo de Deep Learning basado en redes neuronales LSTM.
